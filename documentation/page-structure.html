Page Structure

Every page shares the same header, offcanvas mobile nav, search modal, toast container and footer, followed by page-specific content inside <main id="main-content">. This keeps navigation and theming consistent everywhere.

PagePurpose
pages/index.htmlPrimary homepage — hero, rituals, ingredients, products, consultation CTA, trust, testimonials, journal, newsletter
pages/home-2.htmlAlternate full-bleed magazine-style homepage hero
pages/shop.htmlProduct catalog with chips, filter toolbar, grid and pagination
pages/product-details.htmlSingle product page — gallery, tabs, related/recently viewed
pages/ingredients.htmlA–Z ingredient glossary with search and letter filter
pages/ingredient-details.htmlSingle ingredient profile template
pages/consultation.htmlConsultation packages, practitioner profile, booking form
pages/certifications.htmlQuality standards, badges (demo), FAQ
pages/services.htmlService overview cards
pages/service-details.htmlReusable single-service template
pages/about.htmlBrand story, mission, sourcing, timeline, team, testimonials
pages/blog.htmlWellness journal listing with category filters
pages/blog-details.htmlArticle template with TOC and ingredient callouts
pages/contact.htmlContact info, contact form, wholesale enquiry, map placeholder
pages/404.htmlBranded not-found page
pages/coming-soon.htmlPre-launch page with countdown and email signup

Asset paths

All pages under pages/ reference assets as ../assets/css/... and ../assets/js/.... If you move a page out of that folder, update its relative paths accordingly.
