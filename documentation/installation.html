Installation

1. Extract the template

Unzip ayurveda-naturals.zip. You'll find the folder structure below:

ayurveda-naturals/
├── assets/       (css, js, images, fonts)
├── pages/        (all HTML pages)
├── documentation/
├── sitemap.xml
└── robots.txt

2. Run locally

Because pages use relative asset paths (../assets/...), open them through a local server rather than double-clicking the file:

cd ayurveda-naturals
python3 -m http.server 8000
# then visit http://localhost:8000/pages/index.html

3. Deploy

Upload the whole ayurveda-naturals/ folder to any static host (Netlify, Vercel, GitHub Pages, or a standard web server). No build step is required — every page is plain HTML, CSS and JavaScript.

4. Dependencies (CDN-loaded)

  • Bootstrap 5.3.3 (CSS + JS bundle)
  • Bootstrap Icons 1.11.3
  • Google Fonts — Playfair Display & Manrope

No npm install or build tooling is needed; everything loads from CDNs listed in each page's <head>.
